### // SYSTEM ARCHITECTURE & PROFILE OVERVIEW

```text
[IDENTITY]      : Samet (Samettr08)
[FOCUS]         : Malware Analysis | Reverse Engineering | Low-Level Systems | Web Automation
[CORE LANGUAGES]: Python, C++, C, JavaScript
[ENVIRONMENT]   : Windows Kernel/Userland, Linux, Threat Intelligence Sandboxes
[LOCATION]      : Turkey
```

* **Tersine Mühendislik (Reverse Engineering):** PE x86/x64 ikili dosya analizi, dinamik hata ayıklama (x64dbg), dekompilasyon (Ghidra, IDA Pro), DLL hooking ve WinAPI çağrı izleme.
* **Zararlı Yazılım Analizi (Malware Analysis):** Statik ve dinamik davranış analizi, bellek dökümü incelemesi, paket yakalama, SHA-256 hash çıkarma ve tehdit istihbaratı.
* **Düşük Seviye & Sistem Geliştirme:** C ve C++ ile sistem seviyesinde araçlar, uç nokta koruma mekanizmaları, ağ filtreleme ve bellek denetimi.
* **Python Web & Otomasyon Mimarisi:** FastAPI, Flask ve Django ile backend/API yönetimi, web kazıma (scraping), bot altyapıları ve operasyonel otomasyon araçları.
* **Ağ & Donanım Güvenliği:** Windows Güvenlik Duvarı kuralları, port denetleyicileri ve çevresel aygıt (kamera/mikrofon) donanımsal gizlilik kontrolleri.
